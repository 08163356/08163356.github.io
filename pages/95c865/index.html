现有的平台，支持直接通过命令发送按键给应用：

adb shell input keyevent 7    # for key '0'
adb shell input keyevent 8    # for key '1'
adb shell input keyevent 29    # for key 'A'
adb shell input keyevent 54    # for key 'B'
adb shell input text "ANDROID"
