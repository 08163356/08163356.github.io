前端模拟面试 Skill - 个人定制版

📦 文件说明

本目录包含基于你个人简历和项目经历定制的前端模拟面试Skill。

文件列表

文件名说明使用场景
frontend-interview.zipSkill安装包解压后安装到.codebuddy/skills/目录
使用说明.md完整使用指南了解Skill功能和使用方法
面试准备清单.md快速准备指南面试前必看，准备要点和检查清单
README.md本文件快速了解整个Skill体系
面试记录-YYYYMMDD-HHmm.md面试报告（生成）每次面试后自动生成

🚀 快速开始

1. 安装Skill

# 解压 frontend-interview.zip
# 将 frontend-interview 文件夹复制到
.codebuddy/skills/frontend-interview

2. 准备面试

阅读 面试准备清单.md，梳理：

  • ✅ 配置平台项目（重点）
  • ✅ 电视系统性能优化
  • ✅ Vue原理复习
  • ✅ 性能优化方法论

3. 开始面试

在对话框输入：

开始模拟面试

4. 查看报告

面试结束后，报告会自动保存到本目录，格式：

面试记录-20251216-1430.md

💡 使用建议

面试前

  1. 必看：面试准备清单.md
  2. 重点梳理：
    • 配置平台项目（未完整总结，重点）
    • 电视系统性能优化（量化数据）
    • Vue原理复习
  3. 准备STAR法则：每个项目都准备Situation-Task-Action-Result

面试中

  1. 结合项目：不要只说理论，要结合实际项目
  2. 量化数据：63%、60万等数据要准确
  3. 深度准备：面试官会4层追问，准备好细节
  4. 坦诚回答：不会的不要胡编，可以说正在学习

面试后

  1. 认真读报告：关注评分和改进建议
  2. 记录问题：记下回答不好的问题
  3. 针对性改进：根据报告制定学习计划
  4. 定期练习：每周1-2次，不同技术方向

📞 使用帮助

常见问题

Q: 面试官会问哪些问题？ A: 优先从你的项目出发（配置平台、电视系统等），然后深入技术原理，最后考察思维能力。

Q: 如何准备配置平台项目（2024.5至今）？ A: 这是重点！准备：并行编辑方案、内存泄漏定位、OnlyOffice难题、性能优化、项目管理。

Q: 面试时长多久？ A: 建议30-40分钟技术深挖 + 5分钟开场和反问。

Q: 报告保存在哪里？ A: 自动保存到当前目录，格式：面试记录-YYYYMMDD-HHmm.md

Q: 可以多次使用吗？ A: 可以！建议每周1-2次，每次关注不同技术方向。
