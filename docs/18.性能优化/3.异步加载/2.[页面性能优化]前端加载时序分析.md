## 当前问题

使用window.open(),第二个参数是"_blank"打开新页面的时候中间有两秒的白屏时间

## 思路分析

| 可能原因                                                     | 方案                                                         | 实现                                                         |
| ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 目标页面的资源（如 HTML、CSS、JS 文件）加载耗时较长。        | 在主页面中，提前请求目标页面的资源（HTML、CSS、JS 等），将其缓存到浏览器中，减少新窗口中资源加载的时间。 | 在主页面中使用 `<link>` 或 `<script>` 标签预加载目标页面资源。<br />也可以使用 JavaScript 的 `fetch` 方法提前缓存内容。 |
| ~~网络延迟或服务器响应慢。（不可能）~~                       |                                                              |                                                              |
| 当 `window.open()` 打开新页面时，浏览器会先创建一个新的窗口或标签页，默认显示空白页（`about:blank`），直到目标页面加载完成。 | 骨架屏                                                       |                                                              |
| 新页面的资源（如同步 JavaScript 文件）加载时阻塞了页面渲染。 |                                                              |                                                              |

## 主要思路方案：

- [x] 添加加载动画或占位内容。（骨架屏幕，和2类似，目前并行编辑和直接打开的时候是没有骨架屏的）
- [x] 使用占位页面跳转到目标页面。（类似骨架屏，暂不考虑）
- [x] 优化函数加载的时序
- [ ] 提前预加载目标页面资源。（预加载、SSR）
- [ ] 优化目标页面的加载速度。（优化空间不多）
- [x] （done）prepare接口改成并行
- [x] 检查是否有浏览器插件干扰。（是的，至少影响了一两秒，这个是无法改变的）

```
使用轻量级、隐私模式、去除插件测试后，插件影响确实大
```
