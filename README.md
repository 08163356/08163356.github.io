# aXing's blog

个人技术博客，VuePress 2 + vuepress-theme-hope。

- 线上：<https://ablog.axingit.top>（日常入口）
- 镜像：<https://blog.axingit.top>（GitHub Pages，不作为发布目标）
- 源码：`docs/`
- 本地：`npm install` 后 `npm run dev`，构建 `npm run build`
- 发布到 ablog：`npm run deploy`（本机构建 `site-out`，rsync 到 `8.135.9.12:/var/www/blog`，保留 `.well-known`）

`docs/` 按主题分册。敏感稿不在这个公开仓，本机另存。

他山之石（CSS / JS / ES6 / React / Vue2 笔记）保留在站内，当索引和对照，不是对外教程站。
